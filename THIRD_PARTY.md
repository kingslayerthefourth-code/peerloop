The application uses the browser's IndexedDB, service-worker, Intl and print APIs. GitHub Actions and GitHub Pages provide free verification and static publication. Codex and browser automation were development tools.

The captioned demo was encoded with FFmpeg 7.1 obtained through imageio-ffmpeg from the standard Python package registry, and composed with Pillow using actual application captures. Those development binaries are not distributed in this repository. It contains no music, synthetic narration, paid media or real student records.
